# Bonfire для Windows

Лёгкий десктоп-клиент на [Tauri 2](https://tauri.app). Это окно, которое открывает
сервер Bonfire: интерфейс тот же, что в браузере, и обновляется вместе с сервером.
Окно рисует встроенный в Windows WebView2, поэтому установщик весит несколько мегабайт.

Что умеет клиент сверх вкладки браузера:

- **трей** — крестик прячет окно, Bonfire продолжает работать в фоне;
  левый клик по значку открывает окно, в меню по правому — «Сменить сервер» и «Выйти»;
- **уведомления Windows** о новых сообщениях, запросах на переписку и входящих звонках;
- **один экземпляр** — повторный запуск показывает уже открытое окно.

## Перед первым запуском

Сервер работает по https с собственным сертификатом. Установите `certs\ca.crt`
в «Доверенные корневые центры сертификации» (двойной щелчок по файлу →
«Установить сертификат» → «Текущий пользователь»), иначе клиент не подключится.

## Сборка

Нужны [Rust](https://rustup.rs) (stable, MSVC), Visual Studio Build Tools с
компонентом «Разработка классических приложений на C++» и Node.js.

```bash
cd desktop
npm install
npm run build
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`.

Для разработки — `npm run dev`: окно с отладочной сборкой, изменения в Rust
пересобираются автоматически.

Иконки генерируются из `icon.svg`: `npm run icons`.

## Как устроено

- `src/index.html` — страница выбора сервера, показывается при первом запуске.
- `src-tauri/src/lib.rs` — окно, трей, сохранение адреса сервера
  (`%APPDATA%\local.bonfire.desktop\settings.json`) и проверка навигации:
  окно открывает только свой сервер, остальные ссылки уходят в обычный браузер.
- Уведомления отправляет сам веб-интерфейс через стандартный `Notification` API,
  а плагин `tauri-plugin-notification` превращает их в уведомления Windows.
