# Bonfire через Tailscale

Сервер Bonfire работает на домашнем компьютере, а друзья подключаются к нему
через [Tailscale](https://tailscale.com) — защищённую сеть поверх интернета.
Белый IP не нужен, в интернет наружу ничего не открывается: чат видят только те,
с кем вы поделились компьютером.

## Для друзей

1. Установите Tailscale: https://tailscale.com/download и войдите
   (через Google, Microsoft или GitHub — как удобнее).
2. Откройте ссылку-приглашение, которую вам прислали, и примите доступ.
3. Откройте **https://home-pc.tailf5ad3c.ts.net:8443** — в браузере или в
   десктоп-клиенте Bonfire (при первом запуске он спросит адрес сервера).
   Сертификат настоящий, ничего дополнительно устанавливать не нужно.
4. Зарегистрируйтесь и добавьте собеседников кнопкой «+» по имени пользователя.

Tailscale должен быть включён, пока вы пользуетесь Bonfire.
Чат работает, только когда включён компьютер, на котором запущен сервер.

## Для владельца сервера

### Один раз

1. В админке Tailscale на странице **DNS** (https://login.tailscale.com/admin/dns)
   включите **MagicDNS** и **HTTPS Certificates**.
2. Из корня проекта запустите:

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\tailscale-cert.ps1
   ```

   Скрипт получит сертификат Let's Encrypt на имя компьютера, подключит его в
   nginx и переключит LiveKit на Tailscale-адрес — без этого звонки до друзей
   не дойдут.
3. Пригласите друзей: в списке устройств (https://login.tailscale.com/admin/machines)
   у этого компьютера — меню «⋯» → **Share…** → ссылка-приглашение.
   Так друзья получают доступ только к этому компьютеру, а не ко всей вашей сети.
4. Рекомендуется ограничить, какие порты видят друзья: в **Access controls**
   разрешите приглашённым только порты Bonfire — 8443 (сайт), 7881 и 7882
   (звонки). Иначе им доступны и другие службы компьютера.

### Регулярно

Сертификат действует 90 дней. Раз в 2–3 месяца запускайте скрипт снова —
он выведет дату, до которой действует новый сертификат.

### Если не подключается

- **VPN на сервере.** VPN с полным туннелем (например, AmneziaVPN) может
  блокировать входящие подключения через Tailscale. Проверьте с выключенным
  VPN; если помогло — настройте в нём раздельное туннелирование и исключите
  сеть Tailscale `100.64.0.0/10`.
- **Звонки в локальной сети.** После скрипта LiveKit объявляет Tailscale-адрес,
  поэтому звонить смогут только устройства с включённым Tailscale.
