# Bonfire на сервере

Сервер: `141.133.200.47` (Beget, Санкт-Петербург, Ubuntu 24.04), код лежит в `/opt/bonfire`.
Адрес для друзей: **https://141-133-200-47.sslip.io**

Регистрация — только по инвайт-коду. Сертификат Let's Encrypt Caddy получает
и продлевает сам. Вход на сервер — только по SSH-ключу.

## Пригласить друга

```bash
ssh root@141.133.200.47
cd /opt/bonfire
docker compose exec backend python manage.py invite --note "Петя"
```

Каждый код — на одну регистрацию. Полезные варианты:

- `--count 5` — сразу несколько кодов;
- `--days 7` — код сгорит через неделю, если им не воспользуются;
- `docker compose exec backend python manage.py invites` — список: какие коды
  свободны, кто каким зарегистрировался.

## Обновить Bonfire

У себя на компьютере, из корня проекта, в Git Bash:

```bash
./scripts/deploy.sh root@141.133.200.47
```

Скрипт отправит текущие файлы проекта (без секретов и всего, что в `.gitignore`),
пересоберёт и перезапустит контейнеры. Переписка и аккаунты сохраняются,
миграции базы применяются автоматически.

## Резервные копии

Каждый день в 04:00 — в `/opt/bonfire/backups`, хранятся две недели.
Сделать копию вручную: `bash scripts/backup.sh`.

Восстановить:

```bash
gunzip -c backups/bonfire-ДАТА.sql.gz | docker compose exec -T db psql -U bonfire -d bonfire
```

Копии лежат на том же сервере: если сервер пропадёт целиком, пропадут и они.
Время от времени скачивайте свежую копию себе:

```bash
scp "root@141.133.200.47:/opt/bonfire/backups/*" ./backups/
```

## Секреты

`/opt/bonfire/.env` создан при первом развёртывании (пароль базы, ключ подписи
входа, ключи LiveKit). Он есть только на сервере — не удаляйте его: с новым
`JWT_SECRET` все выйдут из аккаунтов, а с новым паролем базы контейнер базы
не сможет подключиться к уже созданным данным.

## Если что-то не работает

```bash
cd /opt/bonfire
docker compose ps                    # все ли контейнеры запущены
docker compose logs --tail 50 caddy  # сертификаты и входящие запросы
docker compose logs --tail 50 backend
docker compose restart               # перезапустить всё
```
